## 什么是 ndpc？

Ndpc 为命题逻辑和经典一阶逻辑的[自然演绎](https://wikipedia.org/wiki/Natural_deduction)证明引入了一套标记语言，并支持验证、格式化和HTML导出。

与现有同类工具相比，ndpc 更易使用，其语法类似手写证明，无需重新学习。
